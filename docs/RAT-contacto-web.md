# Registro de actividades de tratamiento: «Contacto a través de la web»

Ficha para añadir al registro de actividades de tratamiento (art. 30 RGPD) de la Iglesia Evangélica Bautista de Tudela. Borrador para revisión de Carlos Campos.

| Campo | Contenido |
|---|---|
| Responsable | Iglesia Evangélica Bautista de Tudela, NIF R7139385D, C/ Mediavilla 21, bajo, 31500 Tudela (Navarra), a través de su congregación Iglesia Bautista Internacional de Logroño |
| Actividad | Atención de mensajes enviados por el formulario de contacto de iglesiabautistalogrono.com |
| Finalidad | Responder a la persona que escribe |
| Base jurídica | Consentimiento (art. 6.1.a RGPD), recogido con casilla no premarcada; se conserva prueba (fecha, hora y versión de la política) en el propio mensaje |
| Interesados | Personas que escriben desde la web |
| Categorías de datos | Nombre, correo electrónico y el contenido del mensaje. No se piden datos de creencias; si la persona los incluye por iniciativa propia, se tratan solo para responder (art. 9.2.a) |
| Destinatarios | Ninguno |
| Encargados | Cloudflare, Inc. (alojamiento y antirrobots); Resend, Inc. (envío del correo) |
| Transferencias internacionales | EE. UU.: Marco de Privacidad de Datos UE-EE. UU. y cláusulas contractuales tipo |
| Plazo de conservación | El necesario para responder; máximo un año en el buzón de correo |
| Medidas de seguridad | HTTPS; sin base de datos; claves solo en Cloudflare; buzón con verificación en dos pasos; acceso limitado a quien atiende el correo |
